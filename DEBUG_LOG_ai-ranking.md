## B.5 Root cause (step 6)

```
ROOT CAUSE (one sentence): The apparent same-second bypass is permitted because the direct and semantic detectors emit separate verse_detections events, while shouldRankDetections only examines the semantic event passed to it and has no memory of the direct event.
WHY CHAIN: one final transcript enqueues direct and semantic jobs independently -> the workers emit independent frontend events -> the frontend invokes the batch-local ranker gate separately for each event -> a semantic event containing two candidates but no direct item can invoke DeepSeek even if a 0.92 direct hit was emitted during the same second.
CAUSE->SYMPTOM EVIDENCE: Direct and semantic enqueues are independently shown at src-tauri/src/commands/stt/mod.rs:532-540 and :588-596; independent emits are at src-tauri/src/commands/stt/live_session.rs:421 and :652; the batch-local gate is at src/lib/deepseek-ranker.ts:65-71; the exact 0.92/0.90 comparison passed its deterministic unit probe.
SCOPE LIMIT: Existing runtime tracing logs detection events and successful AI selections, but not gate decisions or attempted ranking requests. Therefore it cannot establish from the supplied same-second timestamp whether the reported live call was the separate semantic event or whether the user setting exceeded 0.92.
```

## B.9 Root-cause writeup (step 9)

```
ROOT-CAUSE WRITEUP - ai-ranking-direct-hit-suppression - 2026-07-31
1. SYMPTOM: A ranking call and a 92% direct Genesis 2:1 hit were observed in the same second.
2. ROOT CAUSE: The gate is correct for one batch but has no cross-event awareness; direct and semantic results are delivered as separate events.
3. MECHANISM: The semantic event reaches the gate without the direct item, so its semantic candidate count can trigger a ranking request.
4. HOW IT WAS FOUND: The exact 0.92/0.90 condition was tested, then the Rust enqueue/worker/emit path and frontend event-to-gate path were traced end to end.
5. THE FIX (why correct): No application change was made during investigation. Any fix must define a cross-event suppression window or merge/coordinate candidates before ranking; changing the numeric comparison would not address this cause.
6. VERIFICATION: The focused ranker test passed with a 0.92 direct fixture and the probe was reverted. Source tracing confirms independent workers and emits.
7. PREVENTION & FOLLOW-UPS: Record rank-gate decision traces with event sequence, threshold, direct-hit summary, candidate IDs, and call/suppression outcome before the next live run. Use the resulting trace to calibrate a cross-event gate.
```
