SabbathCue listens to a live sermon audio feed, transcribes speech in real time,
detects Bible verse references — both explicit citations and quoted
passages — and renders them as broadcast-ready overlays via NDI for live
production.

The SabbathCue dashboard during a service shows the live transcript on the left,
detected verses in the centre column, and the verse queue plus broadcast preview
on the right.

## Get started in two commands

<Callout title="Prerequisites" type="info">
  You'll need [Bun](https://bun.sh), the [Rust toolchain](https://rustup.rs),
  [Python 3](https://www.python.org/), and your platform's [Tauri v2
  prerequisites](https://v2.tauri.app/start/prerequisites/) installed first. See
  [Prerequisites](/docs/getting-started/prerequisites) for the full list.
</Callout>

```bash
git clone https://github.com/Bongisto/SabbathCue.git && cd SabbathCue
bun install && bun run setup:all
bun run tauri dev
```

That's it. `setup:all` runs the idempotent setup phases - Python venv, Bible
downloads, SQLite build, ONNX export, embeddings, and Vosk assets - and
`tauri dev` boots the desktop app. See the [installation guide](/docs/getting-started/installation)
for a guided walkthrough.
